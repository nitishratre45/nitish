# OS — PROGRAM-01: CPU Scheduling

## Aim
Simulate FCFS, SJF, Round Robin and Priority CPU scheduling algorithms and calculate waiting time and turnaround time.

## Files
- `cpu_scheduling.py`: runnable Python code.
- `README.md`: overview and run instructions.
- `LINE_BY_LINE_EXPLANATION.md`: explanation of statements, logic, formulas, and viva questions.

## Algorithms
1. FCFS — First Come First Serve
2. SJF — Shortest Job First
3. Round Robin — time quantum is 2
4. Priority Scheduling — smaller priority number is treated as higher priority

## Run
```bash
python cpu_scheduling.py
```

## Assumptions
All processes arrive at time 0. FCFS, SJF, and Priority are implemented non-preemptively in this example.
